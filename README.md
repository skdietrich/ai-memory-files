# The AI Memory Files

A cinematic, editorial website promoting a 15-second Hollywood investigative thriller concept: *The File You Never Wrote*.

Created for Dr. Stephen Dietrich-Kolokouris.

## Concept

An artificial intelligence has assembled an intimate psychological portrait of a real person—combining personal disclosures with interpretations and assumptions they never confirmed. The site presents this idea with the restraint and visual language of a prestige documentary.

## Live Site

Once deployed to GitHub Pages, the site will be available at:

```
https://YOUR-USERNAME.github.io/ai-memory-files/
```

## Local Preview

Open `index.html` in any modern browser. No build step required.

## Deploy to GitHub Pages

1. Create a new public repository on GitHub (suggested name: `ai-memory-files`)
2. Push this folder to the repository
3. Go to **Settings → Pages**
4. Set source to **Deploy from a branch**
5. Select `main` branch and `/ (root)` folder
6. Save

The site will be live within a minute or two.

## Design Notes

- Editorial archival aesthetic
- Bone paper background, black ink, thin rules
- Large serif headlines (Cormorant Garamond)
- No gradients, no cards, no SaaS patterns
- Fully responsive
- Self-contained (fonts loaded from Google Fonts)
